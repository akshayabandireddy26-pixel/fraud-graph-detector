
# Fraud Graph Detector API

FastAPI is a light and fast service to detect possible cycles of money flow (money laundering cycles) in a graph using cycle detection algorithms (specifically‚ Depth First Search) implemented in FastAPI․

Highlights

Graph Engine: makes use of an adjacency list and performs cycle detection via a Depth First Search algorithm using recursion․
FastAPI Backend: provides autogenerated API documentation UI via Swagger UI․
Production Ready: provides an easy deploy to platforms like Render․
Endpoints

POST /check-transactions checks whether a set of transactions lead to cyclic payment transfers․
